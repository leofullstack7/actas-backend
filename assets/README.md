# Assets del acta (Word)

Coloca aquí el **escudo del Concejo** (solo la imagen del logo, sin texto):

**`logo_concejo.jpg`** (también acepta `.jpeg` o `.png`)

- Formato: JPG o PNG
- Tamaño sugerido: al menos 300×300 px

El encabezado del `.docx` (título «Concejo de Manizales», tipo de sesión, número de acta y fecha) se genera en código a partir del texto del acta.

Si reemplazas el archivo, vuelve a desplegar el backend en Railway.
